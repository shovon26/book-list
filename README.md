# Gutenberg Books Explorer

Gutenberg Books Explorer - Browse, Search, and Save Your Favorite Books.

## ✨ Features

✨ Features
- 📚 Book Browser – Browse a wide collection of books from the Gutenberg public API.
- 🔍 Real-time Search – Instantly filter books by title with live updates.
- 📂 Genre Filter – Easily sort books by genre or topic using a dropdown.
- ❤️ Wishlist Support – Like books to add them to your wishlist, saved via localStorage.
- 🗂️ Multi-page Navigation – Paginate through books with intuitive next/previous or page-number controls.
- 🧭 Multiple Views – Dedicated pages for Home (book list), Wishlist, and Book Details.
- 📸 Visual Book Cards – Clean and stylish book cards with title, cover, author, genre, and ID.
